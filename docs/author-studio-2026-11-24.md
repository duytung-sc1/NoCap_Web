# Author Studio follow-up and reading home

Follow-up correction: the owner wanted the original landing page retained. The original Swiss hero, philosophy and showcase sections were restored at the top of `/` for all visitors, including signed-in users and browsers with reading history. The replacement guest/personal home components are no longer mounted by App. Recent reading and recommendations remain below the landing sections; current-profile guards protect private showcase content. Author Studio and the other workspace changes remain separate. Regression coverage checks both signed-in and guest users with browser documents.

This pass supersedes the initial author-editor limitations in product-evolution-2026-11-24.md and the completed stages in workspace-ui-2026-11-24.md.

The owner selected first-work and cover approval, then author-controlled publishing of subsequent chapters. Key metadata or cover changes return to review. Autosave only changes private drafts. The publishing screen explicitly selects chapters and requires rights confirmation. Unselected chapters remain private, including from admin review. The admin can inspect the public edition and unpublish/suspend a work with a recorded reason.

Author Studio now has a cover-based work list with real counts, filters, manuscript chapter rail, chapter search and reordering, volume labels, rich formatting (bold/italic/headings/lists/quotes), preview, focus mode, cover upload and separate metadata/publishing tabs. Tiptap 3.35.0 runs locally in the browser; no Tiptap Cloud or paid service is used. Pending reviews freeze the submitted edition. Autosave serializes revision-guarded snapshots, retains typing that arrives while a save is in flight, and pauses on errors/conflicts. No offline or crash-recovery guarantee is made.

The global font guard now leaves ProseMirror's owned DOM intact. The editor applies Be Vietnam Pro or Plus Jakarta Sans using chapter content independently of interface language. This fixes an observed browser freeze while entering Vietnamese, reproduced during manual browser testing and covered by a regression check.

Guest home has a concise reading/writing introduction, actual catalog covers and three real destinations. Signed-in home puts Continue reading, saved ideas and recent documents first. Existing genre/book recommendations and the recent-card local-document library action are preserved. Library/Explore styling reduces banner decoration, clarifies import/search/filters and uses consistent book cards. No invented bestseller/engagement labels are added.

Responsive checks cover desktop 1440×1000 and mobile 390×844, English/Vietnamese interface, light/dark, Vietnamese content in English UI, cover upload→review, rich text persistence, selected first-chapter approval, subsequent chapter publishing and retention of another private chapter. The first local browser run exposed a font-guard/editor redraw loop; this was fixed before release. Focus mode on mobile hides chapter navigation and secondary review information to prioritize the writing area. Local test manuscripts are not production publications.

Official reference: https://www.webnovel.com/inkstone/help/list?id=6 documents work creation, chapters, periodic draft saving, publishing and cover/book review. NoCap adapts that workflow to its own branding and the owner's moderation choice. Public author profiles, reader comments, income, scheduling, revision history, OCR and whole-document automatic translation remain outside this release. AI remains the admin pilot with ten shared requests/day; proposed storage tiers remain unenforced.
