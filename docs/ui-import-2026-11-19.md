# Document import UX — local validation, 2026-11-19

## Behavior

- Import defaults to the open folder in the personal library. The dialog allows choosing the library root or another folder, including nested paths.
- Device files, HTTPS documents and assembled chapter books use the same destination selector and commit path.
- The destination is captured when the picker/download starts. Changing library navigation while a file is being prepared does not redirect that import.
- Saving the file, catalog metadata, folder membership and account sync outbox uses one IndexedDB transaction. A removed destination rejects the import rather than silently saving to the library root.
- Preparation, saving, success and failure have accessible feedback. Success shows the saved folder and an Open to read action. Reader Back retains folder context.
- A failed list refresh after a successful commit does not report a failed import; committed data remains visible and can be opened.
- Duplicate submissions are blocked. Cancelled picker results and results from an account that has since changed are ignored.
- Folder map navigation and its existing Back behavior remain unchanged.
- Full selected folder paths wrap below the selector, including on narrow phones. Vietnamese titles and folder names retain Be Vietnam Pro inside English UI; English UI uses Plus Jakarta Sans.
